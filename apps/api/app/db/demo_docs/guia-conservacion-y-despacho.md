# Guía de conservación y despacho — Banquetería Volcán Llaima (demo)

DOCUMENTO SINTÉTICO DE DEMOSTRACIÓN.

## Temperaturas
- Refrigerador de lácteos y masas: entre 1 °C y 4 °C.
- Cámara de carnes y pescados: entre 0 °C y 2 °C.
- Congelador: −18 °C o menos. El helado se guarda a −18 °C y no se vuelve a congelar una vez descongelado.
- Preparaciones calientes para despacho: sobre 65 °C hasta servir.

## Tiempos
- Las empanadas horneadas se despachan dentro de 2 horas desde que salen del horno.
- Los canapés se arman como máximo 3 horas antes del evento.
- El ceviche se prepara el mismo día y se mantiene bajo 5 °C.

## Despacho
Cada pedido sale con una guía que indica productos, cantidades y temperatura al salir.
Las bandejas de cartón se cubren con film y van en cajas térmicas.
El conductor confirma la entrega con una foto de la mesa armada.
